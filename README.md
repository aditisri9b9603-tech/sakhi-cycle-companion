# 🌸 SakhiCycle — Your Gentle Period & Wellness Companion

> *Bloom in every phase of you.*

SakhiCycle is a warm femtech Progressive Web App (PWA) built for Indian girls and women — offering cycle tracking, AI-powered guidance, anonymous community support, and holistic lifestyle care.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🗓️ Cycle Tracker | Log mood, flow, and symptoms daily |
| 🤖 Sakhi AI | Ask anything about your health — gently |
| 🥗 Lifestyle & Diet | Phase-aware nutrition and wellness tips |
| 🛍️ Period Products | How-to guides & Indian brand recommendations |
| 👩‍⚕️ 24/7 Gynaec Support | Find specialists near you |
| 💬 Anonymous Forum | Share experiences — no names, no judgment |
| 🤝 Buddy System | Connect with a cycle pen-pal |
| 🎵 Good Vibes | Music, affirmations & mood boosters |
